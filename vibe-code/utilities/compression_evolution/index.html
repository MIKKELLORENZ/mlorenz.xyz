Compression Evolution

A genetic algorithm invents lossless compression algorithms, starting from nothing but counting which byte values are common. Every candidate is a real compressor. It is run, its output is counted in bytes, and the champion is decoded again and checked bit for bit.

The grey lines on the chart are gzip, bzip2, xz, zstd, PNG, WebP, FLAC and others, measured on the same bytes. The point is not to beat them. It is to watch what a compressor is take shape: what it looks at, what it guesses, and where the bits go.

By default one design is evolved for all five files at once. Pick a single file to specialise; it starts from the shared design rather than from nothing.
