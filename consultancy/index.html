Case study

BioPilot · In development

Building the operating system for cell therapy research

The problem

Cell therapy labs run on a patchwork of disconnected tools — Benchling for notebook entries, separate LIMS for inventory, FlowJo for FACS analysis, spreadsheets for DOE. File management is clunky, integrations are spotty, and there’s no single source of truth connecting a protocol to its results.

The solution

BioPilot is a single integrated platform with cell-therapy-native ontologies, a day-by-day protocol scheduler, native FACS gating workspace, DOE optimization boards, full inventory management, and audit trails — all designed around how cell therapy researchers actually work.

  • Native gating replaces the FlowJo → CSV → Benchling ingestion pipeline
  • DOE optimization as the default working surface — no more export-to-stats-tool
  • Deep ontology: cell lines ↔ media ↔ compounds ↔ hardware ↔ processes
  • One platform from exploratory R&D through GMP compliance
